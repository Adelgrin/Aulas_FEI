A evolução do SOA para microserviços se deu a necessidade de granunalizar os processos, para uma melhor integração entre processos atuais e futuros

## Limitações observadas
* Serviços muito grandes
* Governança pesada (mudanças devem ser documentadas)
* ESB centralizador
* Deploy lento
* Baixa autonomia das equipes
## O serviço consiste em
ser desenvolvido separadamente
implantado separadamente
escalação separadamente
ter próprio banco de dados
